01 — How I test

From first build to real players.

Your posting asks for someone who owns quality and works with the community. This is how I worked on my own games.

Play

Every build

I play each new build myself and check that nothing broke since the last one.

Check

UI and text too

Overlapping HUD, blurry text, wrong sizes — I treat them as bugs, not details.

Playtest

Outside players

I ask friends who have never seen the game to play it, so they find what I had missed.

Fix

Feedback into fixes

I share what I find with the team and fix many issues myself in Unity.

02 — Bug reports

Bugs I found and fixed.

Real entries from my commit history, written up the way I would file them for a QA team.

Example report

Character passes through the sofa obstacle

Game / area
Falling Dream · falling stage
Steps
1. Enter the dream from the bed.
2. Fall into a sofa obstacle.
Expected
The player hits the sofa and has to dodge it.
Actual
The player falls straight through it. The obstacle has no effect.
Cause / fix
The character was on a collision layer that ignored obstacles. Removed it from that layer.
Severity
High — breaks the core challenge
Status
Fixed · Aug 2026
